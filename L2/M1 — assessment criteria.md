# Milestone 1 — Assessment Criteria

This is a planning milestone. Prototyping is a good part and a good instrument to plan things. You are not required to code yet; however, it might be very helpful for you to arrive at your conclusions faster.

Milestone 1 is worth **20 points — one fifth (1/5) of your total grade for this course**. One grade is given to the whole group. The 20 points are split across 4 criteria, 5 points each. **Late submissions receive at most 50% of the points.**

1. **Task definition (5 pt)** — what the agent does, for whom, why it has to be an agent and not a script or a ChatGPT message, and which parts you'll solve with plain code instead of an LLM call.

2. **Initial architecture (5 pt)** — in the course vocabulary (perceive → think → act): your tools (external + internal), memory (if any, and why), and reasoning pattern — name it if you can, cite a pattern we haven't covered if it fits. In the initial architecture, you can stick to ReAct for now as the simplest thing possible, and you can name and consider more complicated reasoning patterns if you'd like to test them. Try to explain why this could be necessary for your agent.

3. **Failure map (5 pt)** — 5–7 concrete ways the agent can break, and for each one how you figured it out (prototype run, article, specific weird input, group discussion).

4. **Evaluation plan (5 pt)** — 3–5 concrete test inputs and what counts as "worked" vs "didn't work".

**Deliverable:** one `.md` in your repo. Optional small prototype with examples quoted inside.
